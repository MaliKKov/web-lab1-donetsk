# История города Донецка

Лабораторная работа №1 по дисциплине «WEB-программирование».

**Тема:** Изучение HTML-тегов и CSS-стилей.

## Описание проекта

Многостраничный информационный сайт, посвящённый истории, инфраструктуре, культуре и достопримечательностям города Донецка.

## Использованные технологии

- HTML5 — структура и содержимое страниц.
- CSS3 — оформление и адаптивная вёрстка.
- Microsoft Visual Studio — среда разработки.

## Структура сайта

- `index.html` — главная страница с описанием города и галереей.
- `history.html` — история города и таблица событий.
- `infrastructure.html` — география, карта, районы и транспорт.
- `culture.html` — культура, театры, музеи и известные личности.
- `about.html` — информация о разработчике.
- `contact.html` — форма обратной связи с HTML5-валидацией.
- `css/styles.css` — стили сайта.
- `img/` — изображения.

## Как запустить

1. Скачать проект на компьютер.
2. Распаковать архив.
3. Открыть файл `index.html` в браузере.
4. Использовать навигационное меню для перехода между страницами.

Для отображения встроенной карты требуется подключение к интернету.

Форма обратной связи является демонстрационной и не отправляет сообщения на сервер.
